# Edge runtimes (Linux / SBC)

Software for **gateway-class** boards that run Linux — not bare-metal firmware.

| Platform | Folder | Stack |
| --- | --- | --- |
| Raspberry Pi | [`raspberry_pi/`](raspberry_pi/) | Python 3 + MQTT (paho-mqtt) |

Use when you need: local buffering, Node-RED, multiple protocol bridges, or a field gateway that aggregates ESP32/STM32 nodes.

Controller scope: [docs/REFERENCE_SCOPE.md](../REFERENCE_SCOPE.md).
